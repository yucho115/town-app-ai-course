## 要件としてはめっちゃ大雑把でwebアプリ×AIです
中町の構想的には
テーマ:チャットボットをベースとした多数のAI機能を備えたアプリを作成する
初級:Azure OpenAIを用いたチャットボットを実装しよう！
フロント・バック共にある程度の誘導や参考記事を用意してチャットボットを作成してもらう。
中級:RAGを用いて、特定の情報に特化したチャットボットにしよう！(テキスト情報のみ)
Azure AI Search(ベクトルデータベース)を用いて、用意したデータ(架空のTOWN株式会社とか？)を読み込ませてその会社に特化したチャットボットへ改造する
上級編:pdfやエクセルなどにも対応させよう！
中級編ではテキストデータのみを対象としていたが、上級編ではpdfやエクセルデータも取り込めるようにする(UI上で)。
以降+α
(インターン生がやりたいものを選んで自分で進めるようにしたいが、僕のいる間にできないのでとりあえず特別編1だけやる感じで)
特別編1:AIエージェント化させよう！
以下の機能を実装
・上級編までで読み込ませたデータを元に、チャットボットを資料作成できるエージェントに進化させる(〇〇の会議の議事録作ってー、××の在庫情報csvで出力してーなど)
・自分のメールに定期送信する機能
などなど(上級まででの難易度調整を考慮してエージェント機能を用意する)
技術スタックは
フロント:HTML, CSS, JS
バック:FastAPI(Python)
その他:Azure(OpenAI, Blob Storage,  AI Search, Logic Apps)
で考えています
