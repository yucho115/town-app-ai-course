# chat botアプリ
SAKURA APIを用いたチャットボットWebアプリケーションです。

## 機能
**1. ユーザーが入力したメッセージを画面上に表示する**<br>
 ユーザーがテキストボックスに入力した内容を「Enterキー」または、「送信ボタン」をクリックすることでチャット画面に表示させる

**2. ユーザーのメッセージに対してのAIからの応答を受け取り画面上に表示する**
 メッセージを送信すると、サーバーからAIの応答を受け取りチャット画面に表示させる

 **3. AIの応答が表示されるまでのあ緯度「考え中...」というメッセージを表示する**
 AIの応答を待っている間、ユーザーに処理中であることを示すために「考え中...」というメッセージを表示する

 **4. トーク履歴を保持する**
  ユーザーがメッセージを送信しても、これまでのトーク履歴が消えずに残るようにする

## 技術スタック:
- フロント:HTML, CSS, JS
- バック:FastAPI(Python)
